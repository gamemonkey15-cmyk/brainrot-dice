How do these virtual dice work?

This website uses a random number generator to assign a color to each virtual die. Each color has an equal chance of being selected. All dice always display the number 1.

Click "Go Again" to roll all the dice on this page again.

You can choose between 1 and 20 dice. Each die has six possible colors: Red, Orange, Yellow, Green, Blue and Purple.

About us

Roll Color Dice is a free online color dice simulator for games, challenges, and choosing between different options. Pick how many dice to roll, select a background, and roll again.

This is an independent fan-made project and is not affiliated with Steal a Brainrot or Online-Dice.com.
