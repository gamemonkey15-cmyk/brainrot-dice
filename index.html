How do these virtual dice work?

This website uses a random number generator to assign a color to each virtual die. Every color has an equal chance of being selected. All dice always display the number 1.

By clicking on the "Go Again" button you can re-roll all the dice on this page.

This page allows you to choose any number of dice between 1 and 20. Each die has six possible colors: Red, Orange, Yellow, Green, Blue and Purple.

About us

Roll Color Dice is a free online color dice simulator. You can use it for games, challenges, and deciding between different options. Choose how many dice to roll, select a background theme, and roll again whenever you want.
